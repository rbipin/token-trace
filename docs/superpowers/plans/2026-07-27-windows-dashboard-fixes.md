# Windows Dashboard Fixes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `uv tool install git+...` include the built dashboard frontend (via CI auto-commit of `src/dashboard/static/`), and make `tokentracer dashboard --daemon` on Windows start immediately and report when already running.

**Architecture:** Two independent fixes per the spec (`docs/superpowers/specs/2026-07-27-windows-dashboard-fixes-design.md`): (1) un-gitignore the Vite build output and add a GitHub Actions workflow that rebuilds and commits it on pushes to `main` touching `frontend/**`; (2) extend `src/dashboard/daemon.py` so the Windows path queries task status, runs the task immediately after creation, and stops it on uninstall, with `install()` returning `bool` (False = already running) consumed by `DashboardCommand`.

**Tech Stack:** Python 3.11 stdlib (`subprocess`, `schtasks`), pytest with `unittest.mock`, GitHub Actions with pnpm/Vite.

## Global Constraints

- `tokentracer schedule` / `unschedule` (collector job) must NOT be touched — the dashboard daemon stays fully separate (spec: "No cross-wiring in either direction").
- macOS daemon behavior unchanged except `install()` now returns `True`.
- No new runtime dependencies — stdlib only.
- Run tests with `python -m pytest -q` (all) or targeted `python -m pytest tests/<file> -q`.
- Commit messages: imperative mood, ~50-char summary, NO `Co-authored-by:` trailers.
- Windows Scheduled Task name is exactly `ai-token-tracer-dashboard` (existing `_TASK_NAME`).

```python
def install(port: int) -> bool:
    """Install and start the dashboard daemon.

    Returns True if installed/started, False if it was already running.
    """
    system = platform.system()
    if system == "Darwin":
        _install_macos(port)
        return True
    if system == "Windows":
        return _install_windows(port)
    raise RuntimeError(f"unsupported OS for dashboard daemon: {system}")
```

Replace `_install_windows()` and `_uninstall_windows()`, adding a status helper:

```python
def _query_windows_status() -> str | None:
    """Return the task's Status field ('Running', 'Ready', ...), or None if absent."""
    result = subprocess.run(
        ["schtasks", "/Query", "/TN", _TASK_NAME, "/FO", "LIST"],
        capture_output=True, text=True,
    )
    if result.returncode != 0:
        return None
    for line in result.stdout.splitlines():
        if line.strip().startswith("Status:"):
            return line.split(":", 1)[1].strip()
    return ""


def _install_windows(port: int) -> bool:
    if _query_windows_status() == "Running":
        return False
    argv = resolve_executable() + ["dashboard", "--port", str(port)]
    action = " ".join(f'"{a}"' if " " in a else a for a in argv)
    result = subprocess.run(
        ["schtasks", "/Create", "/F", "/TN", _TASK_NAME,
         "/TR", action, "/SC", "ONLOGON", "/RL", "LIMITED"],
        capture_output=True, text=True,
    )
    if result.returncode != 0:
        raise RuntimeError(f"schtasks /Create failed: {result.stderr.strip()}")
    result = subprocess.run(
        ["schtasks", "/Run", "/TN", _TASK_NAME],
        capture_output=True, text=True,
    )
    if result.returncode != 0:
        raise RuntimeError(f"schtasks /Run failed: {result.stderr.strip()}")
    return True


def _uninstall_windows() -> None:
    subprocess.run(  # stop a running dashboard first; ignore failures (may not be running)
        ["schtasks", "/End", "/TN", _TASK_NAME],
        capture_output=True, text=True,
    )
    result = subprocess.run(
        ["schtasks", "/Delete", "/F", "/TN", _TASK_NAME],
        capture_output=True, text=True,
    )
    if result.returncode != 0 and "cannot find" not in result.stderr.lower():
        raise RuntimeError(f"schtasks /Delete failed: {result.stderr.strip()}")
```
